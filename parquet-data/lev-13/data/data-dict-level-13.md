# 🧾 HCES 2023–24 — LEVEL 12 Data Dictionary

Link: https://microdata.gov.in/NADA/index.php/catalog/237/data-dictionary/F13?file_name=Level%20-%2013%20(Section%2014)


| Column Name                 | Description                                                   |
| --------------------------- | ------------------------------------------------------------- |
| **Survey_Name**             | Name of the survey (Household Consumption Expenditure Survey) |
| **Year**                    | Survey year (2023–24)                                         |
| **FSU_Serial_No**           | First Stage Unit (FSU) serial number                          |
| **Sector**                  | Sector of residence (Rural / Urban)                           |
| **State**                   | State code / name                                             |
| **NSS_Region**              | NSS regional classification                                   |
| **District**                | District code / name                                          |
| **Stratum**                 | Sampling stratum identifier                                   |
| **Sub_stratum**             | Sub-stratum within the stratum                                |
| **Panel**                   | Panel number used in sampling                                 |
| **Sub_sample**              | Sub-sample identifier                                         |
| **FOD_Sub_Region**          | Field Operations Division sub-region                          |
| **Sample_SU_No**            | Sample Second-Stage Unit number                               |
| **Sample_Sub_Division_No**  | Sample sub-division number                                    |
| **Second_Stage_Stratum_No** | Second-stage stratum number                                   |
| **Sample_Household_No**     | Sample household number                                       |
| **Questionnaire_No**        | Questionnaire serial number                                   |
| **Level**                   | Data level identifier (Level-13)                              |
| **ITEM_CODE**               | Code of the consumption item                                  |
| **FIRST_PURCHASE_NUMBER**   | Number of first-hand purchases                                |
| **PURCHASED_ON_HIRE**       | Indicator whether item was purchased on hire                  |
| **FIRST_PURCHASE_VALUE**    | Value of first-hand purchases (₹)                             |
| **REPAIR_COST**             | Repair & maintenance cost / construction services cost (₹)    |
| **SECOND_HAND_NUMBER**      | Number of second-hand purchases                               |
| **SECOND_HAND_VALUE**       | Value of second-hand purchases (₹)                            |
| **TOTAL_EXPENDITURE**       | Total expenditure on the item (₹)                             |
| **MULTIPLIER**              | Survey multiplier (weight)                                    |
